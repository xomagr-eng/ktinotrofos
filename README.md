# 🐄 Κτηνοτρόφος ΤΝ

Offline / PWA web app έξυπνης διαχείρισης κοπαδιού για τον Έλληνα κτηνοτρόφο — αδελφή εφαρμογή του [Αγροτεχνίτη ΤΝ](https://xomagr-eng.github.io/agrotexnitis/).

**Live:** https://xomagr-eng.github.io/ktinotrofos/

- 17 είδη (βοοειδή, βουβάλια, πρόβατα, αίγες, χοίροι, πουλερικά, κουνέλια, ιπποειδή, μέλισσες) · 128 φυλές (όλες οι ελληνικές αυτόχθονες αιγοπροβάτων + ξένες)
- Μονάδες & κοπάδια με χάρτη/GPS, μητρώο ζώων (ενώτια), ημερολόγιο με κόστη/έσοδα & χρόνους αναμονής φαρμάκων
- Αυτόματο πρόγραμμα φροντίδων, κύηση/επώαση, πρόβλεψη παραγωγής & εσόδων
- Θερμικό στρες (THI) από ζωντανό καιρό Open-Meteo, νερό/τροφή, σιτηρέσιο, έλεγχος συμπτωμάτων (νοσήματα υποχρεωτικής δήλωσης)
- FAMACHA© από φωτογραφία, οδηγός BCS

Όλα τα δεδομένα μένουν τοπικά στη συσκευή (localStorage). Οι τιμές είναι ενδεικτικές και δεν αντικαθιστούν τον κτηνίατρο.
